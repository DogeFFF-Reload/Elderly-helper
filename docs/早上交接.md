## 3. 每人起床先做什么

### 硬件
1. 读 `docs/RH56F2_实测.md`（5 分钟）。**不要跑** WeChat kit 里的 `START_HAND.bat` / `GO_HAND.ps1`：接口和主脑对不上，而且会往占位地址写动作。这只手不需要烧录。
2. 要到 F2 的寄存器表（问赞助商要 RH56F2 / RH56FX 通信手册）。拿到后改 `rh56_register_map.py`、只读确认、再把 `VERIFIED` 改成 True。
3. 手不回话时：**24V 和蓝盒 USB 都断开 → 先插蓝盒 → 再插 24V → 等 10 秒**。千万别读 4032 以上的地址（会把手卡死）。
4. 机械臂 Panthera：执行端接口已经定好（`POST /pose?name=&hand=`，收到就回 200；`POST /stop` 急停），臂的 SDK 接在 `hand_controller/arm_service.py` 的 `_execute` 里，别改接口。

### 队长
1. 看 `docs/演示脚本_3分钟.md`（台词 + 每段按什么键 + 出问题怎么办），按自己的说话习惯改。
2. 看 `docs/评委问答.md`，组织全员背。
3. 知会一声：大屏加了"床边执行端"、操作台加了急停按钮（`Esc`），都动了你的 `ui/` 文件。

### 演示
1. 真摄像头实拍一次 `python -m vision.fall_bridge --camera --preview`，按 README §11.3 调参；录 2~3 段跌倒视频做 Plan B。
2. 打印举牌、准备药盒托盘。
3. `deploy/setup_x5.sh` 的 b 角色加了两行（pyserial、dialout），重新跑 setup 后要**重新登录**一次。

### 全员
1. 按 `docs/演示脚本_3分钟.md` 彩排 ≥3 次，填计时表。
2. **12:00 前**：软件合并、打 `demo-final` 标签。之后不改代码，出问题回滚到标签。
3. 冻结后录一段完整演示视频备用。
