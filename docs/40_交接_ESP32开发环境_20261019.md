## 五、立即开工：3 条命令

```powershell
# 1) 确认环境（预期：esp32:esp32 3.3.12 在列表中）
& 'D:\arduino-cli\arduino-cli.exe' core list

# 2) 插上板子后，看是哪个 COM 口
& 'D:\arduino-cli\arduino-cli.exe' board list

# 3) 编译/上传/看串口（把 COM5 换成实际口、路径换成实际草图）
& 'D:\arduino-cli\arduino-cli.exe' compile --fqbn esp32:esp32:esp32 --board-options PartitionScheme=huge_app "D:\ArduinoProjects\app"
& 'D:\arduino-cli\arduino-cli.exe' upload  -p COM5 --fqbn esp32:esp32:esp32 --board-options PartitionScheme=huge_app "D:\ArduinoProjects\app"
& 'D:\arduino-cli\arduino-cli.exe' monitor -p COM5 -c baudrate=115200
```

## 六、必须知道的红线

1. **分区表必须选 `Huge APP (3MB No OTA/1MB SPIFFS)`**。
   蓝牙协议栈本身就占 ~1.1 MB，用默认分区会顶到 ~84%，几行代码就可能 `region overflowed`；换 huge_app 后回落到 ~35%。
2. **草图必须是「同名文件夹里的同名 .ino」**。
   Arduino 的硬性规定，例如 `D:\ArduinoProjects\app\app.ino`。直接放一个散装 `app.ino` 编译不了。
3. **供电与地线**。
   ESP32 由充电宝(USB 5V)供；大电流负载（电机/舵机）走 24V 电池经降压模块，**绝不能**用板载 3.3V；所有器件 **GND 必须共地**。
4. **GPIO 选择**。
   避开 strapping 脚 `0 / 2 / 12 / 15`（D12 上接了东西会导致烧录失败，先拔线再烧）；`34~39` 只能做输入且无内部上拉。
5. **上传失败先做这两件事**：把上传速率降到 115200；按住板子 **BOOT** 键再点上传。
6. **不要脑补硬件**。接线、机械、整车集成不在本交接范围，遇到不确定的**问用户**。
