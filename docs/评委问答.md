# 评委问答小抄 · CareMate

**一句话**：能演示的就说能，没做的就说没做；每个答案都指到一个按钮、一条测试或一块屏。

**怎么用**：
- 先给结论，再说机制，最后指证据；每题控制在 30 秒、3~4 句。
- 不会的就说【待确认】，不编数字、不编价格、不编“已经上线”。
- 评委追问细节，主讲不硬撑，直接转给对应同学：“这块软件/硬件同学更熟。”
- “谁来答”按 v2.5 §7.1 分工：**主讲**（队长）、**软件**、**硬件**、**演示**。

## 一、必答 6 题（v2.5 §10）

### Q1. 为什么要机械臂？发个通知不就行？

**谁来答**：主讲（硬件可补）

**30 秒回答**：因为通知只能叫醒家属，不能替老人做事。递药、按 SOS 都是物理动作；SOS 还能直接按老人家里已有的呼叫器，不用改造。软件负责判断和通知，臂负责最后一下。

**当场证据**：
- 操作台按 **`3`** 看递药，大屏右上角“床边执行端”同步画臂和手。
- 按 **`F`** 走保命链，看臂按 SOS、家属端收到。
- 回归：`test_handover_chain`、`test_fsm_escalation`。

---

### Q2. LLM 幻觉会不会害人？

**谁来答**：软件

**30 秒回答**：LLM 没有执行权。摔倒、SOS、120、健康复述、教学步骤全走状态机或 scripted，LLM 只润色白名单里的台词。单句 3 秒超时、出错冷却 60 秒、内容检查不过就回落，它最多说错一句话，不能做一个动作。教学步骤只来自 `guides.json`，联系人也只在家属白名单里，LLM 拨不了陌生人。

**当场证据**：
- 操作台点 **“🤖 模拟 LLM 越权：按 SOS”**，看请求被 supervisor 拦下。
- 点 **“给张三打电话”** 看联系人白名单拦截；教学只按 `guides.json`，不现编。
- 回归：`test_agent_supervisor`、`test_llm_fallback`。
- 操作台顶部“台词：scripted / llm”；`/api/state` 的 `llm` 字段有计数和最近错误。

---

### Q3. 摄像头对着卧室，隐私怎么办？

**谁来答**：主讲

**30 秒回答**：画面只在本地做姿态推理，大屏显示的是双色骨架，不存原始影像；健康档案只存数字和时间；回声只存称呼、口头禅、语气词。要说清楚：llm 模式下，语音转写后的文字会发到主办方 API；原始音频和视频不出户。

**当场证据**：
- 大屏左侧骨架：左半身青、右半身橙，告警变红。
- 家属端健康日报里的记录是数字和时间，不存原话；回声授权页能看到学到的三项文字特征，点收回即删。
- 回归：`test_voice_profile`、`test_health_readback`。

### Q4. 误报怎么办？漏报怎么办？

**谁来答**：演示

**30 秒回答**：规则看过程，不看单帧：1 秒内髋部下降至少半个躯干长、躯干变横，2 秒没站起来就报；看不到人也算没站起来，防床后遮挡漏报。缓慢滑倒要低处横躺 12 秒；坐下、弯腰、床上躺着不报。报了可以按绿键或说“我没事”取消，时间线留痕。合成 9 个场景 0 误判，但真人实拍调参还没完成【待确认】。

**当场证据**：
- 摔倒询问时按 **`O`**（绿键）或点 **“我没事”**，看大屏取消。
- 回归：`test_fall_detector`；`vision/eval_falls.py` 可回放录好的骨架。
- 调参窗口：`python -m vision.fall_bridge --camera --preview`。

### Q5. 回声是不是在骗老人？

**谁来答**：主讲

**30 秒回答**：不是声音克隆，也不冒充。开口必说“让我替她说两句”，只复用她说过的话，再附她最近一条真实留言，不替家属做新承诺。家属在家属端亲手授权才启用，一键收回就删除档案。

**当场证据**：
- 家属端“回声授权”开启/收回；收回即从 `voice_profile.json` 删除。
- 回归：`test_voice_profile`。
- 档案只有称呼、口头禅、语气词三项文字特征，不采集声纹。

---

### Q6. 才等几秒就升级，现实可行吗？

**谁来答**：软件

**30 秒回答**：5 秒、3 秒、10 秒都是演示参数，为了 3 分钟走完；真实部署按老人反应速度和访谈结果调。`config.py`、`config.local.json`、环境变量、运行中的 `/api/params` 都能改，不是写死。等待越短越安全，但误报打扰也越多，这个阈值要和家属、护理人员一起定。

**当场证据**：
- 操作台右侧“演示参数：日 5s · 夜 3s · 120 10s”。
- `GET /api/params` 看当前值和合法范围；`POST /api/params` 现场改。
- 回归：`test_config_params`。

## 二、评委很可能追问的 15 题

### Q7. LLM 断网 / 超时怎么办？

**谁来答**：软件

**30 秒回答**：默认 `scripted`，零网络依赖；`llm` 模式单句 3 秒超时回落，网络错一次冷却 60 秒，不每句干等。内容检查不过也回落。台词在单独线程里生成，不占总线锁，后面的 SOS 台词不会被卡住。

**当场证据**：
- 操作台日志会出现“LLM 超时 → 回落 scripted”（大屏不显示）。
- `/api/state` 的 `llm` 字段有计数和最近一次错误。
- 回归：`test_llm_fallback`。

---

### Q8. 机械臂会不会伤到老人？

**谁来答**：硬件

**30 秒回答**：物理和软件两道。物理侧要求靠近人体低速、工作空间避开头部、物理急停一按断电，具体实装到哪一步【待确认】，现场由硬件同学守着急停。软件侧已落地：轻握最紧只到开合度 50、力度上限 300 克（真手地址核对后才会真写）、最长 60 秒；`Esc` 立刻停发动作，真手 `/stop` 写 -1 停住；总线过期动作直接丢，断链就停、保持姿态。手册没有急停寄存器，拔 24V 是最后一道。

**当场证据**：
- 按 **`Esc`**，大屏“床边执行端”变灰、显示“急停中”，操作台出红色提示；解除只能点“解除急停”并确认。
- 总线 5 秒过期直接丢、不重发；断链保护见 README §10.8。`test_estop`、`test_arm_link`、`test_hand_driver`。
- 轻握限幅（`GENTLE_MIN_OPEN`）和 300 g 力度上限在执行端代码里，测试盯着。

---

### Q9. 家属一直不回怎么办？

**谁来答**：软件

**30 秒回答**：30 秒没人确认就通知下一位联系人；都不回，老人会听到“家里人暂时都没回复，需要的话您说帮我打120”。不是无限等。`family_ack_timeout` 可配。

**当场证据**：
- 按 `F` 后先别按 `A`，等 30 秒，看操作台“已通知”变成下一位（问答时用日志说明，不在 3 分钟主线里等）。
- 回归：`test_fsm_escalation`。
- 台词在 `lines.json` 的 `next_contact`、`all_contacts_silent`。

---

### Q10. “确认”会不会被误用？血压的“对”会不会把 120 确认吃掉？

**谁来答**：软件

**30 秒回答**：两个确认窗有优先级：120 确认窗 > 血压复述确认。120 只在老人主动说“帮我打120”后开 10 秒窗，必须听到“确认”才拨；超时或“取消”都不拨；血压的“对/确认”不会把 120 的确认吃掉。120 本身是模拟，不真拨。

**当场证据**：
- 操作台点 **“帮我打120”**，看右侧“120 确认窗”倒计时，再点 **“确认”** 或 **“取消”**。
- 回归：`test_fsm_escalation`。
- 规则写在 README §8 第 3 条。

---

### Q11. 成本和落地：哪些是真的，哪些是 mock？

**谁来答**：主讲

**30 秒回答**：仓库里没有完整 BOM【待确认】，价格不报。真的部分：主脑、状态机、白名单、LLM 回落、三块屏、Vosk 离线 ASR、TTS、跌倒规则、RH56F2 通信；其中跌倒只在合成场景实测；TTS 在笔记本上用系统自带中文语音（Microsoft Huihui），X5 上用 espeak / piper。没做的：臂 SDK 没接、只打印动作，真手 F2 地址表没拿到、当前只读，120 是模拟，床头盒协议是草案，两块 X5 还没实机跑过。所以现在是能端到端演示的原型，不是可交付产品。

**当场证据**：
- `docs/RH56F2_实测.md` 看真手到哪一步。
- `tools/preflight` 看执行端在不在；大屏右上角“床边执行端”；操作台日志。
- 不报价格、不报量产时间。

### Q12. 为什么用两块 X5？断网还能用吗？

**谁来答**：硬件（软件补离线）

**30 秒回答**：现场只有两块 X5，按现在建议的映射：X5-A 视觉，X5-B 主脑 + 三块屏 + 语音 + 执行端。保命链从主脑到执行端走本机回环，不经过 Wi-Fi；视觉跨板走网络，断了还有操作台“触发摔倒”兜底。断网时 `scripted`、Vosk 离线、本地屏都能跑；`llm` 模式会回落。X5-B 的 USB 口够不够接 RS485、麦克风、喇叭，这套映射还要硬件确认【待确认】。

**当场证据**：
- `deploy/start.sh a` / `b` 两块启动脚本。
- `python -m tools.preflight --server http://<X5-B>:8000`。
- 回归：`test_preflight`。

### Q13. 真手现在到底能不能动？

**谁来答**：硬件

**30 秒回答**：能通信，不能动。EB90 经蓝盒（测试时 COM7）、ID 1、115200 已打通，读指令有回包；但 F2 寄存器地址和 V1.09 不一样，手册里的角度地址全是 0xFF，实际地址还没找到，F2 地址表等厂家资料【待确认】，所以 `VERIFIED` 仍是 False，只读。型号后缀 E2/E4 还没确认【待确认】。演示用 mock，大屏动画照常演。

**当场证据**：
- `docs/RH56F2_实测.md`；`rh56_register_map.VERIFIED = False`。
- 大屏右上角“执行端模拟 · 大屏演示”（执行端是 mock 时自动这么显示，不会写“真机同步”）。读 4032 以上会卡死；恢复顺序：24V 和蓝盒都断电 → 先插蓝盒 → 再插 24V → 等 10 秒。
- `python -m hand_controller.arm_service --probe` 只读探测（MOCK_SERIAL=0）。

### Q14. 机械臂怎么知道药盒在哪？能递别的东西吗？

**谁来答**：硬件

**30 秒回答**：现在不做视觉抓取。演示里药盒在固定托盘位，动作是预置 pose，手#1 按关节开合度执行；没学过的物品会被拒绝，AI 会说“我还没学过怎么递，现在只会递药盒”。这是刻意的边界：不会做就不做。

**当场证据**：
- 操作台点 **“把遥控器递给我”**，看拒绝台词。
- `poses.py` 的 `JOINTS` 里每个动作名对应的六关节开合度。
- 回归：`test_handover_chain`。

### Q15. 老人不会说普通话 / 口音重 / 会场太吵怎么办？

**谁来答**：演示

**30 秒回答**：ASR 用 Vosk 离线中文，有同音纠错表；关键指令都用固定短语。识别不到就操作台按 `1`/`2`/`3`，或在“让老人说”输入框直接发文字，走同一个 `/mock/voice` 入口；床头盒绿键现场用操作台 `O` 模拟。方言识别率我们没数据，会场噪音下的识别率还没实测【待确认】。

**当场证据**：
- 操作台快捷键和“让老人说”输入框；`--backend stdin` 键盘当麦克风。
- `voice/asr_bridge.py` 的 `ASR_FIXES`（如“雪压→血压”）。
- 回归：`test_asr_chain`。

### Q16. 演示是不是提前录好的？流程是不是写死的？

**谁来答**：演示

**30 秒回答**：现场软件链路是实时跑的：操作台每个按钮都打公开 HTTP 接口，和 ASR 桥、视觉桥同一入口；`demo_driver` 也只走这些接口。预录视频只是 Plan B，不用它冒充实时。动作是预编排的，不是现场让大模型生成。

**当场证据**：
- 操作台日志带时间戳，按一下动一下。
- `python -m demo_driver --pause` 可逐段走主线。
- 回归：`test_demo_driver`。

### Q17. 打 120 是真的吗？

**谁来答**：软件

**30 秒回答**：不真拨，演示是模拟。流程是真的：老人主动说“帮我打120”，开 10 秒确认窗，听到“确认”才走拨号分支，超时/取消都不拨；拨完的台词会明确说“这是演示模拟”。真实接 120 涉及资质和对接，我们没做。

**当场证据**：
- 操作台 **“帮我打120”** → **“确认”** / **“取消”**。
- `lines.json` 的 `dial_done`：“已经帮您拨打120，这是演示模拟。”
- 回归：`test_fsm_escalation`。

### Q18. SOS 等家属的时候，老人还要药 / 要做手指操怎么办？

**谁来答**：软件

**30 秒回答**：询问、SOS、等家属期间，臂归状态机。用到臂的技能（递药、手指操、猜拳）会被挂起，AI 说“我先顾着您这边的安全，这件事等会儿再帮您做”；不用臂的请求（叫女儿、留言、教学）照常放行。保命链结束——说没事、按绿键、重置——之后自动恢复。

**当场证据**：
- SOS 等待时按 **`3`**，看 `skill_busy` 台词和操作台日志。
- `skills.json` 里每个技能占用哪些资源（`uses`）。
- 回归：`test_agent_supervisor`。

### Q21. 为什么 SOS 之后不立刻举“家人已收到”？

**谁来答**：软件

**30 秒回答**：因为没回执就说“已收到”不诚实。SOS 阶段先按求助键、通知家属；手#1“家人已收到”、手#2“女儿马上到”要等家属在家属端点了“我收到了，马上到”才举。家属不点就继续升级下一位，不假装有人来。

- 回归：`test_fsm_escalation`、`test_handover_chain`。

## 三、上场前 60 秒自检

- 每个答案都能指到一个具体东西：按钮、测试名、屏；指不到就删掉这句话。
- 数字和硬件状态只有三个来源：仓库 README、`_v25_ref.md`、`docs/RH56F2_实测.md`；没有出处就说【待确认】。
- “真手不能动”“120 是模拟”“臂 SDK 没接”这三句要敢说，评委更信诚实的人。
- 主讲被问住时，说“这块请软件/硬件同学答”，不要现场编。
