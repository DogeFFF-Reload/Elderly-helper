# 视觉跌倒报警：你到现场怎么做

这份说明对应新增的 `START_FAMILY_ALARM.bat`。它把人体姿态规则判定出的疑似跌倒，上报给队友 App 所连接的床头服务。原有“只观察”和“完整模拟演示”入口继续各自运行。

## 先把什么发给队友

把本文件和 [硬件/软件 Agent 接入交接](32_Agent_家属App报警接入交接.md) 发给队友，要求拉取团队仓库 `main` 最新代码。

你不用烧录、接线或操作机械手。你的 iPhone 可以继续当摄像头；仓库里的家属 App 是 **Android APK**，应由队友准备运行它的安卓手机。两者是不同角色。

## 第一步：让队友确认床头服务和家属手机

请队友完成：床头服务在线、家属 App 已打开且允许通知、电脑与床头在同一网络。默认床头地址是 `http://10.153.47.252:8013`。

仓库已修复接收端并发去重和同毫秒报警编号冲突，源码版本为 **5.7.1**。这次没有替队友部署到板子；请队友按第32份文档更新。视觉发送器也兼容任务包里的5.7，但并发修复只有部署新服务后才生效。

## 第二步：先检查连接，不响手机

在仓库根目录的 PowerShell 中，只运行：

```powershell
.\START_FAMILY_ALARM.bat --check-link --mode dry
```

此命令不打开摄像头。它先检查床头版本，再发 `dry:true`，核对事件号、来源和回执。看到“健康检查和dry回执通过；没有建立真实警报”即完成。连接失败时停止在这一步，把结果路径交给队友；不要反复运行真正报警指令。

如果队友改了床头IP，在本页每条命令后加 `--family "http://新的IP:8013"`。

## 第三步：确认家属手机能收到一条测试警报

队友拿着家属手机、知道这是现场测试时，运行：

```powershell
.\START_FAMILY_ALARM.bat --send-test --mode live
```

此命令不打开摄像头，但会建立一条真实测试警报。让队友检查手机是否出现红色警报、铃声或震动，再在 App 里点“知道了”。程序显示 `bedside_accepted` 只证明床头已收下，**只有队友看到或听到手机报警，才算手机这一段验收完成**。

队友任务包描述前台约3秒、守护服务约10秒轮询。本次尚未现场测量；后台是否可用还取决于安卓通知和后台权限。完全强行停止 App 不能等同于普通退到后台。

## 第四步：启动真正的视觉报警

**用电脑摄像头**，运行这一条：

```powershell
.\START_FAMILY_ALARM.bat --camera 0 --mode live --preview --duration 300
```

**用 iPhone 摄像头**，把下面地址替换为手机摄像头 App 已确认可用的完整 MJPEG 地址：

```powershell
.\START_FAMILY_ALARM.bat --phone-stream "http://手机IP:端口/完整视频流路径" --mode live --preview --duration 300
```

二选一即可。手机固定，人正常走动；电脑摄像头模式下电脑也固定，肩部和髋部尽量持续入镜。普通活动用于检查取景和误报，不需要真人摔倒。窗口按 Q 或 Esc 退出；默认300秒自动停止，`--duration` 最多600秒，需要继续观察时重新运行。

此入口不播放询问提示音。摄像头画面只在内存和本机预览中处理，不上传照片。检测到疑似跌倒后，队友的家属 App 负责手机端声音和震动。

如果只想看画面、不允许真实报警，把 `--mode live` 改成 `--mode off`。`dry` 会联网验证格式但不建立警报；`off` 完全不访问床头。

## 看到什么算成功

| 显示 | 实际含义 | 你需要做什么 |
|---|---|---|
| 正在观察 | 正在处理可用的人体姿态 | 保持机位固定，做普通活动 |
| 未检测到人 / 身体关键点不完整 | 当前骨架不足以正常观察 | 调整距离、取景和光线 |
| 疑似倒地，正在确认 | 规则候选，尚未发送报警 | 保持观察，先不要当作已经通知 |
| 床头已收下报警 | 服务返回与事件号匹配的接收回执 | 请队友确认手机是否响铃 |
| 无扰格式检查通过 | dry测试成功 | 手机不应因为本次请求响铃 |
| 发送失败或回执未确认 | 最多3次发送仍未取得有效回执；可能已经收到但回执丢失 | 保留结果，先排查连接，不要更换事件号重报同一次事件 |

每次运行结束会打印 `summary.json` 路径。默认在 `code/data/family_alarm/批次/`，旁边的 `events.jsonl` 保留每次事件的原事件号、排队和回执。把这一整个批次文件夹交给负责 Debug 的 Agent 即可；其中不含画面、手机视频地址或摄像头账号密码。

## 与旧演示的关系

`START_PC_CAMERA.bat` 仍是本地观察；`START_FULL_VISION_DEMO.bat`、`START_LIVE_VISION_DEMO.bat` 仍连接独立模拟主程序。它们不会自动获得这个原生 App 报警通道。

这次推荐只启动本页的新入口。它直接发送床头接口，不向主脑上报事件、不请求机械臂动作。若队友已用另一台摄像头通过主脑桥接同一个场景，先由队友二选一，避免两个独立检测器各自生成一条报警。

当前验证证明软件链路可运行；真人跌倒识别准确率、现场iPhone持续输入、手机最终响铃仍需各自验收。已有正常活动录制不包含真实跌倒。
