## 5. 动作完成 / 错误回执格式（HTTP 契约 ✅实）

| 请求 | 返回 |
|---|---|
| `POST /pose/{name}` 成功 | 200 `{"ok":true,"did":"pose:thumbs_up","hand":1}`（序列则 `"did":"seq:wave"`） |
| 未知动作 | 200 `{"ok":false,"error":"unknown pose: xxx"}` |
| `POST /handover_med` / `/press_sos` / `/reset` | 200 `{"ok":true,"queued":"..."}`（**异步执行**，回执=已受理非已到位） |
| 服务异常 | 500 `{"ok":false,"error":"..."}` |
| `GET /status` | `{"backend","mock_serial","poses":[...],"recent":[最近20条动作]}` |

**已知诚实缺口**：目前 200=「已下发/线程已排队」，**不是**「物理到位确认」。
真机驱动后补：轮询 `REG_STATUS`(FC03) 直到到位/超时——驱动层槽位留好（`read_register`）。
