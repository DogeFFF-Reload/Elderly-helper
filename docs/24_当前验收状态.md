# CareMate 当前验收状态（2026-10-24 更新）

本页已替换过时的 Modbus、SDK 占位和手机能量阈值说明。操作以 [视觉与手机交接](26_field_handoff_vision_phone_debug.md)、[计划执行结果](27_计划执行结果与剩余验收.md) 为准。只用仓库 arm_service，不启动 kit 的同名服务。

## 已实现并有软件验证

- 主脑、状态机、三块 UI、健康复述、模拟递药、询问与取消、模拟求助、模拟家属确认、手指操。
- iPhone 完整 MJPEG 地址与认证；默认姿态观察只存骨架，不向主程序上报。
- 电脑全屏姿态观察；已完成固定电脑的真人站立、走动、坐下站起，并有操作者确认与坐标哈希。
- 已保存骨架接完整模拟流程；新增实时电脑/手机输入到独立本机模拟主程序。新入口用模拟视频流和保存坐标检查，本轮没有启动真实摄像头。
- 手机部署入口已换成人体姿态；弃用 PHONE_URL / PHONE_ARGS，拒绝不可能触发的阈值38。安装脚本选择手机或 USB 摄像头服务，不同时安装两路。
- T5AI 床头屏、还药、离线语音指令已从 hardware/t5ai-screen 合入；无效长度、不完整音频和识别异常不会执行动作。
- 最终测试数字与结果包见计划执行结果；软件通过不等于物理动作通过。
