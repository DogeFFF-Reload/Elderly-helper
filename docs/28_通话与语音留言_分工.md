## 1. 要做成什么样

| 功能 | 老人端（新页面 `/ui/elder`，床头触屏） | 家属端（`/ui/family` 升级） |
|---|---|---|
| 远程电话 | 大按钮“打电话”→ 选女儿 / 儿子；来电全屏 + 铃声，一点接听；也能说“给女儿打个电话”“接电话”“挂了” | 一键给妈妈打语音电话；妈妈打来时响铃、接听 |
| 语音留言 | 按住说话发给家人；家人的语音一点就播，也能说“听留言” | 按住说话发给妈妈；妈妈的语音能播；对方听没听过有标记 |
| 提醒吃药 | 到点全屏提醒：“把药递给我”/“我已经吃了” | 用药卡（已有） |
| 跌倒紧急呼叫 | 保命链升级通知到谁，床头屏就**自动向谁发起紧急通话**；保命链进行中家属打来**自动接通** | 红色紧急来电；接通后能听到老人那边，照常点“我收到了，马上到” |

技术取舍（评委问到时统一口径）：
- 通话是浏览器 WebRTC **局域网直连**，主脑只转“谁呼谁、怎么连”的信令；不走外网、**不录音、不存通话内容**。
- 不接真电话线：运营商 / 云通信接口要企业资质，比赛现场用局域网通话演示同样的流程，上线时把这一层换成云通信即可。
- 语音留言只存在主脑内存里，最多 30 条，操作台“重置”即清空。
- **状态机没改**：紧急通话是在“通知家属”这一步之后顺带发起的，保命链原来的每一步照旧。

## 4. 接口（给改大屏、语音、脚本用；不要改，要新接口找软件）

- `GET /api/state`（或 `/api/poll`）里的 `comms`：
  - `call`：当前（或刚结束 8 秒内的）通话，没有就是 `null`。字段：`id`、`from`、`to`（`"elder"` 或联系人 id `"daughter"` / `"son"`）、`state`（`ringing` 响铃 / `active` 通话中 / `ended` 已结束）、`emergency`、`auto_answer`、`from_name`、`to_name`、`answered_ts`、`end_text`（如“未接”“已挂断”）
  - `history`：最近 10 通结束的通话；`online`：`{"elder": 老人端开着没, "daughter": ..., "son": ...}`
- `POST /api/call/start {"from","to","emergency"}`、`POST /api/call/hangup {"id","party"}`
- `POST /api/voice_msg?from=&to=&dur=`（正文是录音原始字节）；`GET /api/voice_msg?id=` 取回放
- 事件时间线新增两类：`call`（呼叫 / 接通 / 结束）、`voice`（语音留言）
- 语音指令：“给女儿打个电话”（老人端开着就真打，没开照旧发“请回电”通知）、“接电话”、“不接”、“挂了”、“听留言”
- 页面在线判断：老人端拉 `/api/poll?client=elder`，家属端拉 `/api/poll?client=family:daughter`；15 秒没来算离线，通话中一方离线会自动结束
