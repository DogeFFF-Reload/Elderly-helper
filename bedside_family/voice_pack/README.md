# TTS 台词语音包(voice_pack)

给老人播报的**批量 TTS 语音包**:73 条中文播报,原速 + 慢速两套(老人语速适配,SAPI Huihui 离线合成,16k/16bit/mono WAV,和板上播放链路同规格零转码)。

## 目录

| 项 | 说明 |
|---|---|
| `lines.json` | 台词主表:每条的编号/类别/文本/变量槽 |
| `wav/01_A01_ask.wav … 73_SL47_praise.wav` | 原速版 73 条 |
| `wav_slow/` | 慢速版 73 条(老人聆听;同编号同文本) |
| `../tools/gen_tts.py` | 单条/批量合成脚本(SAPI,Rate 可调) |
| `../tools/gen_pack.ps1` | 一键重生成整包(powershell) |

## 台词分类(前缀即类别)

| 前缀 | 类别 | 例 |
|---|---|---|
| A01-A04 | 应急/跌倒 | 询问"您还好吗"、升级求助、取消 |
| M01-M06 | 用药 | 早/中/晚提醒、喝水、休息、晒太阳 |
| P01-P09 | 陪伴 | 递物/夸奖/讲故事/笑话/晚安 |
| T01-T05 | 留言 | 收到留言/已转告/想念/重播 |
| E01-E02 | 关怀 | 早晚问候 |
| SL01-SL47 | 状态机+演练台词 | 拨号询问、防移动、"没事"确认、猜拳/手指操引导 |

**变量槽**:编号里带 `{}` 的条目按 lines.json 的 slot 填(如药名/时间)。

## 用在哪儿

- X5 板端播放(aplay/espeak 前置缓存):整包 SFTP 推 `/root/caremate/voice_pack/`;
- 家属侧通知、床头盒播报共用一套;
- 更新台词 → 改 lines.json → `gen_pack.ps1` → 推板,固件零改动。

## 板端播放注意

- 采样率必须 16k/16bit/mono(X5 ALSA 与 S3 I2S0 统一规格);
- 音量:`amixer set Master 80%` 起步(老人听力差异大,现场可调);
- 播放/录音共用 I2S0 的板(S3)永远互斥,播放前 `mic_teardown`。
