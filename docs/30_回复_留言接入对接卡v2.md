# 30 回复《留言功能接入摔倒警报 App —— 对接卡 v2》

> 写于 2026-10-24 晚，分支 `software/comms`。一句话：**选 A——中转站就是我们的主脑，已经建好并在公网实测通过**；手板把下面三项配置填进去就能联调。

## 1. 选 A：中转站 = 主脑（已建好）

主脑跑在笔记本上，用 Cloudflare 免费隧道开到公网（不用买服务器、不用账号）：

```bash
cd code
python -m tools.public_link            # 第一次会生成公网钥匙写进 config.local.json，按提示重启主脑
```

它会打印：

```
家属端 App 链接：
  女儿：https://xxxx.trycloudflare.com/ui/family/?as=daughter&key=<钥匙>
  儿子：https://xxxx.trycloudflare.com/ui/family/?as=son&key=<钥匙>
床头盒（手板）配置：
  FAMILY_PUSH_URL=https://xxxx.trycloudflare.com/api/voice_msg
  FAMILY_PULL_URL=https://xxxx.trycloudflare.com/api/family_replies
  FAMILY_PULL_TOKEN=<钥匙>
```

隧道走 TCP 443（`--protocol http2`），校园网 / 热点挡 UDP 也能通。2026-10-24 晚在笔记本上实测：手板格式的 multipart 上传、拉回话、取 WAV 全部从公网地址走通。

## 2. 手板要配的

**推留言**（你们的钩子原样不用改）：`FAMILY_PUSH_URL` 填上面那个地址，multipart 字段就是对接卡里的 `audio` / `time` / `duration` / `elder`。
**要带钥匙**：请求头 `X-CareMate-Token: <钥匙>`（或者 URL 后面加 `?key=<钥匙>`）。不带钥匙回 401。
默认发给所有家属（女儿、儿子各一条），回 `{"ok":true,"voice_id":2,"dur":23.5,"to":["daughter","son"]}`。

**拉回话**：`FAMILY_PULL_URL` + `FAMILY_PULL_TOKEN`，每 5 秒 `GET {FAMILY_PULL_URL}?elder=hand-A&after=<上次的 id>`：

```json
{"ok": true, "replies": [
  {"id": "3", "wav_url": "https://xxxx.trycloudflare.com/api/voice_msg?id=3&key=<钥匙>",
   "from": "女儿", "time": "2026-10-24 21:18:00", "duration": 4.2}
]}
```

- 按时间升序，`after` 填上次拿到的最大 `id`（数字），没有新的就是空数组。
- 用的是对接卡里的 `wav_url` 形式；**URL 里已经带了钥匙**，直接 GET 就行，不用再加请求头。
- 音频是 **WAV 16 kHz / 16 bit / 单声道**：家属端 App 录音就按这个格式录（不是 m4a），手板直接放。
- 多出来的 `from` / `time` / `duration` 字段可以不管，也可以拿来在屏上显示“女儿 21:18 发来”。
- 手板来拉回话时，主脑就知道床头盒在线：家属发语音时 CareMate 会先说“您女儿发来一段语音留言，我放给您听”。

家属的**文字留言**会由喇叭（`voice/tts_player`）念给老人听，不在 `replies` 里。手板如果想自己念文字，告诉我们，加 `{"id": "...", "text": "..."}` 这种条目即可。

手板和主脑在同一个局域网时，也可以直接用 `http://<笔记本 IP>:8000/api/...`，局域网不需要钥匙。

## 3. 第 4 节问题的回答

1. **选 A**，接收 URL 和拉取格式见上面第 2 节（对接卡的 JSON 格式照做了）。
2. **平台**：家属端是“可安装的网页 App”（PWA）。家属手机第一次点开上面的链接 →（安卓 Chrome / 华为浏览器）菜单“添加到主屏幕”→ 之后桌面上有 CareMate 图标，一点就开，**不用连热点、不用输网址**，钥匙也记住了。里面有：摔倒警报（一识别就弹，带现场照片）、老人留言**不用点自动播放**、按住说话回语音（16k WAV）、语音通话、一键 120（打开系统拨号盘）。App 打开时页面在后台也会弹系统通知。
3. **演示当天**：家属手机用 4G 即可；手板连的热点（Mocen_Bear）有外网就行。

## 4. 要注意的

- **免费隧道每次启动地址都会变**（钥匙不变）。演示当天启动一次，把新地址填进手板配置、把新链接发给家属手机；之后别重启隧道。要固定地址得用 Cloudflare 账号 + 自己的域名（命名隧道），以后再说。
- **安全**：公网只开放家属端功能。动臂、操作台、大屏、急停、重置、调参只在局域网，公网请求一律 403；公网也不能冒充老人那头发起通话或拨 120。
- 语音通话跨 4G 靠 STUN 打洞，大多数网络能通；遇到对称型 NAT（少数运营商）打不通时，留言和警报不受影响，通话改用同一热点演示。

## 5. 同批新增：摔倒现场照片

视觉判定跌倒时，在局域网 `POST http://<主脑>:8000/api/fall_photo?src=<来源>`，正文是 JPEG（`Content-Type: image/jpeg`，≤2 MB）。家属端警报卡马上显示这张照片，老人说“没事”或回到空闲 30 秒后自动删除，只存内存、只留一张。手板 / X5 有摄像头的话也可以按这个发。没有照片时家属端显示骨架示意图，并写明“没有收到照片”。
