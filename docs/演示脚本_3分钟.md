# 3 分钟演示脚本 · 一位老人的一天

**依据**：《工作报告 v2.5》§3 主线：0:00 痛点 → 0:20 早上量血压 → 0:50 中午吃药 → 1:20 夜里摔倒 → 2:30 为什么可信。

**用法**：主讲照“主讲台词”念；扮演老人的同学照“老人说”说；操作台同学照“操作台按”按；其余人盯大屏、家属端和计时。

**口径**：询问等待日间 5 秒、夜间 3 秒、120 确认窗 10 秒，都是**演示参数**，台词里要主动说明“真实部署可配置”。

**全队口令**：主讲说“开始”，操作台才按第一个键；主讲说“下一段”，才切；任何人发现异常先看主讲，不抢话。

## 0:00–0:20 痛点：摔了没人知道

**这段的目标（观众记住一句）**：独居老人最怕的不是摔倒，是摔倒后没人知道。

**主讲台词**

> 各位评委，这是 CareMate。先讲一位老人。她独居，孩子在外地。夜里起夜，摔了一跤。怕的是躺多久都没人发现。我们要做的，就是床边这套东西：平时陪她，出事替她喊人。

**扮演老人的同学**：不说话，坐在床边/站位即可。

**操作台按什么**：不按。让大屏停在主界面，不要切屏。

**大屏 / 家属端上会出现什么**：
- 大屏：停在主界面（左侧骨架剪影、右侧事件时间线），给观众两秒看清“这是一个床边系统”。
- 家属端：停在首页，不弹任何卡。

**这段出问题怎么办**：投屏黑屏 → 切备份录屏（若已按检查单备好），主讲照讲，不假装实时；现场噪音大 → 主讲靠近麦克风，第一句放慢。

**数据口径**：§3 要求“访谈原话 1 句 + 1 个有出处的独居老人跌倒数据”。仓库里没有访谈记录原文，也没有可引用的统计数据，所以这版**不报数字、不编原话**。拿到队里的访谈记录后，可把第一段换成老人原话；数据必须带出处，查不到就继续不报。【待确认】

## 0:20–0:50 早上：量血压

**这段的目标（观众记住一句）**：老人随口报的数字，AI 要先复述、她说“对”才记账；偏高自动同步家属。

**主讲台词**

> 第二天早上，她量完血压，说了一句。
>
> CareMate 没有马上记，先复述：高压 138、低压 85，对吗？大屏同时出现复述卡。她说“对”，这才记账。138 比 85 已经偏高，家属端马上收到。数字记错比不记更危险，所以多问这一句。

**扮演老人的同学**（照原话，让意图识别能听懂）：
1. “我刚量了血压 138比85”
2. 等 AI 复述完，说：“对”

**操作台按什么**：先按 **`1`**（报血压），看到大屏复述卡、听到 AI 问完，再按 **`2`**（说“对”）。

**大屏 / 家属端上会出现什么**：
- 大屏：出现血压复述卡“我听到的是高压 138、低压 85，对吗？”；说“对”后卡片消失，时间线记一条；下方字幕同步显示老人和 AI 的原话。
- 家属端：健康日报出现 138/85，标“偏高”（家庭自测参考：收缩压 ≥135 **或** 舒张压 ≥85）；不弹紧急卡。

**这段出问题怎么办**：ASR 没听到 → 操作台按 `1`、`2`；TTS 没声 → 看大屏字幕，主讲把复述念出来；家属端没刷新 → 主讲说“家属端已同步”，操作台日志为证，别在台上反复刷新。

## 0:50–1:20 中午：吃药

**这段的目标（观众记住一句）**：要药不是放一段提醒，是机械臂把药盒真的递到手上。

**主讲台词**

> 中午，她说“把药递给我”。先过意图识别和技能白名单，系统只做学过的动作。臂伸出去，手#1 把药盒递到她手边。大屏右上角的“床边执行端”同步画出臂和手。递药这件事，发一条提醒是做不到的。

**扮演老人的同学**：“把药递给我”

**操作台按什么**：按 **`3`**（要药）。

**大屏 / 家属端上会出现什么**：
- 大屏：右上角“床边执行端”画出臂伸出去、手#1 张开再合拢；时间线出现“递药”；字幕出现 AI 台词“好的，药盒递过来了，您慢慢拿，拿稳了我再收回来。”
- 家属端：这段不弹通知，没有变化。

**这段出问题怎么办**：臂/手不动 → 大屏“床边执行端”照常演，主讲说一句“现场我们用大屏同步展示动作”；执行端是模拟时右上角显示“执行端模拟 · 大屏演示”，离线时显示“执行端离线 · 大屏演示”，照这个口径讲，不硬说真机动了。

## 1:20–2:30 夜里：起夜摔倒

**这段的目标（观众记住一句）**：摔倒后没人回应，系统自己按 SOS、通知家属；家属确认之后才举牌。

**主讲台词**

> 难在夜里。打开夜间模式，大屏亮起月亮。
>
> 她起夜，摔倒了。骨架倒地，大屏出现询问倒计时圈。CareMate 先问：您还好吗？没事按绿键，或说“我没事”。
>
> 她没回应。夜里只等 3 秒——这是演示参数，真实部署会按老人的反应速度配置。
>
> 3 秒一到，大屏弹出 SOS 横幅，臂替她按下床边的 SOS 键，同时通知女儿；另一只手轻轻握住她的手，一握一松，陪她等。家属端弹出紧急卡。
>
> 女儿点“我收到了，马上到”。到这一步，手#1 才举起“家人已收到”，手#2 举“女儿马上到”。家属没回执，我们不说“已收到”。
>
> 这 70 秒，她没碰手机。

**扮演老人的同学**：摔倒后**不出声**。这是关键：无回应才会升级。不要喊“我没事”，那会取消这次求助。

**操作台按什么**：
1. **`N`** 开夜间模式（大屏亮 🌙），停两秒让观众看到。
2. **`F`** 触发摔倒（卧室）。
3. 不按 `O`、不让老人说话，等询问倒计时走完。
4. SOS 横幅出现、家属端弹卡后，家属端点“我收到了，马上到”，或操作台按 **`A`**（女儿确认，等价）。

**大屏 / 家属端上会出现什么**：
- 大屏：先亮 🌙；骨架有倒地过渡动画；出现询问倒计时圈；3 秒后出现 SOS 横幅；右上角“床边执行端”画臂伸过去按 SOS、手#2 开始一握一松（轻握安抚，限力）；时间线连续记录询问、无回应、按 SOS、通知家属；家属确认后，手#1 举“家人已收到”、手#2 举“女儿马上到”。
- 家属端：弹出紧急卡，卡上按钮是“我收到了，马上到”；点完老人那边才举牌。

**这段出问题怎么办**：
- 视觉没触发 → 按 `F`（走 `/mock/fall`，和视觉桥同一入口）。
- 按 `F` 画面还不动 → 先点“🛌 骨架倒地（不触发）”补画面，再按一次 `F`；仍不动就按台词讲完，别在台上排查。
- 家属端没弹 → 直接按 `A`，主讲口述“女儿手机收到了”。
- 举牌/轻握不动 → 大屏动画照常演，主讲说“现场我们用大屏同步展示动作”。
- ASR 把 AI 自己的话听进去 → 防自激会丢；还不行就全程用按钮。
- 误按 `Esc` → 点右上角“解除急停”并确认；**R 不解除急停**，别用重置救急。

## 2:30–3:00 为什么可信

**这段的目标（观众记住一句）**：LLM 只负责说话，保命动作全是确定性代码；隐私只出骨架和数字；参数可配。

**主讲台词**

> 最后说可信。第一，LLM 只负责怎么说，不负责做不做。摔倒后的询问、SOS、120，全部由状态机和白名单决定；越权就被拦。21 套回归、220 条测试盯着这些路径。
>
> 第二，隐私。摄像头画面只在本地算骨架，不存原始影像；健康档案只存数字和时间；回声只学称呼、口头禅、语气词，不做声音克隆。
>
> 第三，询问等 5 秒或 3 秒、120 确认 10 秒，都是演示参数，真实部署可配置。
>
> 我们要的不是会聊天的玩具，是出事时真的会动手的系统。谢谢。

**扮演老人的同学**：不说话，保持刚才的姿势。

**操作台按什么**：不按。**不要按 `R`**，让画面停在救援现场，留到评委问答。

**大屏 / 家属端上会出现什么**：
- 大屏：停在 SOS / “女儿马上到”的救援画面，右上角执行端动作停住；时间线保留整条链。
- 家属端：停在已确认的紧急卡，评委可以走近看。

**这段出问题怎么办**：时间超了 → 砍掉“21 套、220 条”这半句，保留“LLM 只说话、状态机管动作”；投影断了 → 用备份录屏收尾（若已备好），主讲不看屏；评委这时提问 → 主讲先说完“谢谢”，再请对应同学回答，不中途展开。
