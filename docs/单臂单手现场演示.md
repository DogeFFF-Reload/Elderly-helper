```text

python -m hardware_showcase --run arm

python -m hardware_showcase --run hand
python -m hardware_showcase --run deliver
python -m hardware_showcase --run return
python -m hardware_showcase --run sos
python -m hardware_showcase --run sign
```

真实动作需现场有人守急停。脚本记录反馈、失败计数、停止及中断结果；错误或超时自动发 `/stop`，不自动重试。未示教的业务动作会被拒绝。普通命令前需退出点动示教模式。
