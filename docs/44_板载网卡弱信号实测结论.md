# 44 · 板载 USB 网卡弱信号实测结论

> 现象→实验→结论：为什么跨 WiFi 下载慢不能靠改软件参数解决。实测日期 2026-10 月下旬（演示周前）。

---

## 一、现象

- 板子 wlan 实测信号强度在 **-68 ↔ -85 dBm** 两档间反复跳动（RSSI 走低即下载慢、传输抖动）；
- **同一位置**：手机（未移动）信号稳定满格，笔电实测 **-44 dBm**；
- 结论：环境没问题，全部差异来自**板子的 USB 无线网卡自身**（天线/驱动/USB 供电链路）。

## 二、实验：强制低速率档（已还原）

```bash
iw phy0 set bitrates legacy-2.4 5.5   # 固定低速率,牺牲速率换稳
```

实测**无收益**（弱信号下收益为负：速率更低、传输更慢），已还原为自适应速率。教训：**别用固定低速率档对抗信号弱**。

## 三、结论与对策

| 途径 | 有效？ | 说明 |
|---|---|---|
| 软件参数（固定速率、重试参数） | ❌ | 实测无效 |
| **物理改善**（网卡摆朝热点方向、减遮挡、热点就近） | ✅ | 根治路径 |
| 关 WiFi 省电（`wifi-awake.service`） | ✅（另一问题） | 只解决"wlan 掉线/抖动"，**不解决**信号弱 |
| 局域网内部对时延 | — | 板子 localhost 接口 8~17ms：服务不慢，慢在无线链路 |

## 四、还原能力说明

- 板子重插 USB 网卡曾"失联后又自愈"（wlan 自动重连）；
- 自愈后**省电会重新生效**——需复查 `wifi-awake.service` 状态是否已重新生效；
- 参见 `docs/36_热点换段灾情_恢复与新地址交接.md`（网络重建与对时流程）。
