灵巧手 · 单指控制

每根手指单独拖：拖到哪手指走到哪（0 = 握紧，100 = 张开）；拇指旋转 50 是中位，往大转向掌心（对掌，捏东西用）。右边绿色数字是手上读回来的实际开合度。力控 = 每根手指受力到这么大就停，抓软东西调小。手装在臂上、臂正在做动作时会被拒绝。录制时手型会被记下来，也可以「+ 加入脚本步骤」。

3D 虚拟臂 · 鼠标拖动操控

拖黄色指尖 / 浅蓝色手：默认「手导向」——手跟着鼠标走到哪，整条臂（含底座）跟着转过去，尽量保持手掌朝向，够不到时腕部俯仰自动调整；拖动时滚轮 = 把手推远 / 拉近。也可以换成只在竖直平面、只上下、只前后；拖某一节：像拧旋钮一样转这个关节。拖动时真臂实时跟随（用上面的转速），中途随时改方向；半透明黄色是目标，实体是真臂。空白处拖动 = 旋转视角，滚轮缩放，右键平移。紫点是姿态库里的姿态，打开「✎ 编辑姿态位置」后拖紫点 = 改这个姿态的位置（真臂不动，「上方 N cm」会跟着它走；🔒 锁住的拖不动）；粉色虚线是脚本编辑器里当前脚本的路径。右上角的小眼睛：显示每个关节的转环和名字，告诉你拖哪里转哪个关节。

3D 模型按控制器里的关节链和末端长度画（手心距法兰 0.22 m，占位值），和真臂外形只是示意。所有目标照样经过服务端的限位、底座 ±120° 检查；当前已按现场要求关闭桌面高度检查，J1 负方向那一侧有桌子，往下拖时请看着真臂。

① 摆姿态 · 点动示教

进入示教后普通机械臂动作暂时锁定。用拖动条或 ± 把臂摆到位、用末端按钮试抓放；摆好后到下方「姿态库」存起来。急停随时可用。

「边拖边动」：拖动时臂实时跟着走，同时拖多个关节（或连续拖不同关节）它们会一起动；「先设好再一起动」：拖好几个关节的目标（黄框），点「同时执行」让它们同时出发、同时到。转速上限 30°/s，先用低速熟悉。示教底座限于 ±120°；每一帧都按臂的实际位置检查禁区、桌面和限位；单次点动最多 30°、垂直最多 10 cm（保持手掌朝向不变）；转速上限为安全配置的最高关节速度。

臂手协同 · 预设动作

「预设倍速」调整所有预设的快慢（停顿一起缩放）；勾上「与上面的转速同步」后，倍速 = 点动示教里的转速 ÷ 20°/s，拖转速条预设跟着变。在臂当前朝向的竖直平面里完成，不改变左右位置（底座 J1、腕部左右摆 J5 锁住），默认做完回到出发姿态（取消勾选「做完回到出发姿态」就停在动作最后的位置）。先把臂转到面向观众 / 老人的方向（拖 J1），再点按钮；也可以在下面的脚本里作为一步插入。示教模式外也能用；急停随时打断。

T5AI 语音键：说「跟大家挥挥手」「握个手」「帮我递瓶水」……大模型听懂后执行对应的预设动作或编排好的脚本（脚本可以在下面填「语音说法」）；说「停下 / 别动」立即停。

手掌朝向用 J6 设计：J6 = 0 时手朝前、手掌竖直、拇指朝上。挥手、掌心向上请接、数数用了 J6 = 90°，第一次做时看手掌是否朝向预期，反了告诉我改成 −90°。

② 动作编排 · 姿态库 + 步骤脚本

  1. 存姿态：在上面摆好一个位置（待机、取物点、递给老人的位置……），起个名字点「存当前位置」。取物点可一键生成「正上方 N cm」作为接近点。
  2. 排步骤：用「递物再放回」模板一键生成整套流程，或手动添加「移动到姿态 / 手部动作 / 等待」，再改速度、调顺序。
  3. 试运行：可从任意一步开始跑，哪步不对就回去重新存那个姿态——脚本按名字引用姿态，改一处全跟着变。最后保存并绑定到 T5AI 按键。
