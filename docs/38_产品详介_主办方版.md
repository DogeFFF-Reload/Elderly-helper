# CareMate · 床畔亲情守护系统 — 产品详介

> 提交：产品详细介绍（赛主办方版）
> 关键词：适老交互 · 边缘计算 · 隐私优先 · 全离线闭环 · 情感陪伴机器人

---

## 一、产品定位

CareMate 是一套部署于老人床头的**端·边·云协同的家庭陪伴与看护系统**。它让"给子女留句话、听爸妈的原声、和会做动作的双手互动"变成床头屏上的三个大按键——**按下即录、说完即达、点开即听**；同时以独立的看护守护链路，把跌倒等突发风险即时送达子女手机。

设计基线只有一条，贯穿全部技术选型：**全流程跑在家庭本地网络，数据不出户，断网也照常工作。**

---

## 二、我们解决什么问题

| 真实痛点 | CareMate 的回答 |
|---|---|
| 微信/短视频对老人门槛太高，子女想听到爸妈亲口的声音很难 | 床头屏大按键 + 全程语音提示，把「留言/听留言」做成零学习成本的物理按键式交互 |
| 子女想尽孝却看不见爸妈的日常 | 家属 App 随时收听老人原声留言，一键回话；老人在床头按一下就能听到子女的声音 |
| 老人独处的突发风险无人第一时间知晓 | 跌倒检测端事件直送边缘主机，警报到达家属 App：全屏红条 + 警铃 + 高优先级系统通知，家属点击确认形成闭环 |
| 陪伴缺失 | 一对仿生机械手常驻床边：老人按「手部操」跟着做，挥手、点赞、数数，双手还会隔空联动互相回应 |

## 三、系统架构：端 · 边 · 云

| 层级 | 硬件/载体 | 职责 |
|---|---|---|
| **端（老人侧）** | ESP32-S3 床头智能屏：320×240 横屏电容触摸（FT6336）+ ES8311 高保真音频编解码 + 板上功放/麦克风 | 适合老花眼的放大键触控、语音留言录制与播放、状态灯全息反馈 |
| **边（家庭侧）** | **地瓜机器人 X5 边缘计算主机**（单主控；ARM Linux + 板载 10 TOPS 级 NPU） | 家庭**边缘计算中枢**：自研 `arm_service` 服务总线（留言信箱、警报分发、统一指令路由）+ 自研实时运动控制引擎，逐帧驱动仿生机械手 |
| **端（子女侧）** | Android 原生家属 App（v2.0） | 原声留言收听/回话、看护警报、守护状态自查 |
| **检测** | 跌倒事件视觉检测端 | 以事件 API 上报异常，由边缘主机统一分发 |

**数据流**：床头屏 ↔ 边缘主机 ↔ 家属手机全部**局域网直连**，典型接口毫秒级响应（实测 8~17ms）。云端跨网中转的接口已完整预留（`CLOUD_BASE`），子女在异地接收留言即插即启用——演示阶段我们如实做到"未启用云端、全链路本地闭环"。

## 四、核心功能

### 1. 床头双向留言信箱（招牌功能）
- 老人按住「留言」开始说话，**说完随便点一下屏幕就发送**——不需要找到"发送键"，这是为手部不灵活老人专门设计的收尾手势。
- 自研**双缓冲接力上传**：边录边传，一句话音全程不断流（旧方案"录 3 秒停顿上传再录"会截断讲话，已彻底重构）。
- 子女回话自动落盘床头信箱，老人按「听留言」按下灯亮即播，实测**稳态 1 秒内起播**。演示期内已验证 **50+ 条真实家庭留言**的完整收录、存储与双向播放闭环。

### 2. 亲情双手：陪伴即互动
- 由 X5 的**帧级运动控制引擎**统一驱动仿生双手，预置挥手、点赞、手部操、数数等**动作序列库**，老人点按键即跟练——它也是一套轻量化的**居家手部康复训练器**。
- **双手互相呼应**：一只手招手，另一只手回应一个"收到"——把"机器在动"变成"机器在和你打招呼"。

### 3. 语音免伸手
- 老人说"挥手""点赞"这类口语，离线语音白名单直接映射成对应动作，为视力不佳、握力不足的老人保留交互通道。

### 4. 跌倒守护与确认闭环
- 检测端调用 `POST /fall_alarm`（支持 `event_id` 幂等去重，网络重试不重复报警）→ 边缘主机分发 → 家属 App 前台全屏警报 + 警铃 / 后台高优先级通知。
- 家属端 App 内 `ack` 确认，形成"发现—送达—确认"的完整责任闭环。

### 5. 家属 App 的可靠性工程（v1.1 → v2.0 共 11 个版本迭代）
- **断线自愈**：床头设备换网段/换地址，App 自动全网段嗅探找回，不用老人或家属重配。
- **预下载秒播**：列表刷新即后台缓存留言音频，点按即播、几乎零等待。
- **全程可视化反馈**：每一步都有按钮态（下载中/停止播放/失败原因提示），绝不出现"点了没反应"。
- 后台守护服务 + 权限体检 + 拉活机制，App 被系统杀掉也能自行恢复守护。模拟器 16 项回归全绿。

## 五、技术亮点

1. **边缘计算，隐私优先**：语音留言、看护数据全部落盘家庭本地主机，无第三方上传、无账号注册——**老人的声音不出家门**。
2. **全离线闭环**：屏、手、手机在同一局域网完成全部业务功能，不依赖互联网；联网仅是增强项。
3. **单主控一体化中枢**：一块 X5 承担全屋计算与调度（微内核服务总线 + 具身智能执行），部署极简、成本可控、故障面小，家庭场景可复制性强。
4. **声音链路端到端自研**：录音断点续传分片协议、双缓冲边录边传、播放头补偿、触摸防吞点、WiFi 省电治理（systemd 持久化），把消费级硬件的听感/可靠性打磨到演示级。
5. **工程纪律**：GitHub 仓库三套 CI 流水线（固件 / 家属端 / 视觉端）、明确的版本谱系与安全回归，固件真密码与公开仓库物理隔离。

---

## 六、安全与隐私

- 留言音频**仅存于家庭本地**；App 无注册、无登录、不收集任何个人资料。
- 全部接口具备幂等与事件去重设计；HTTPS 升级位已预留（本地自签证书就绪）。
- 公开代码仓库中不含任何真实网络凭证（密码占位符策略 + 构建期注入）。

---

## 七、下一步路线

1. **NPU 下沉**：将跌倒识别、进阶手势、离线语音识别直接部署于 X5 板端推理，进一步降低外设依赖。
2. **云端跨网中转**：激活 `CLOUD_BASE` 预留通道，子女异地也能收听爸妈的留言。
3. **产品化硬件**：床头屏 + 边缘主机 + 机械手整合为一体化床头盒，外壳做适老工业设计与无工具安装。
